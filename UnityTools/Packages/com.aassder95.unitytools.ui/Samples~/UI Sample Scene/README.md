# UI Sample Scene

## 요구 사항

- Unity 2022.3 이상
- TextMeshPro 3.0.7
- Input System 1.14.0
- OSA.Core 플러그인

패키지 본체에는 OSA 의존성이 없지만, 이 샘플의 Rank OSA 모듈과 `UnityTools.Samples` 어셈블리는 OSA.Core를 참조합니다.

## 실행

1. Package Manager에서 `UI Sample Scene`을 Import합니다.
2. `Scenes/SampleScene.unity`를 엽니다.
3. Play Mode에 진입합니다.
4. Sample Lobby에서 Inventory, Rank, Rank OSA, Timer를 선택합니다.
5. 각 화면의 Refresh, Random, Timer 테스트 버튼을 실행합니다.
