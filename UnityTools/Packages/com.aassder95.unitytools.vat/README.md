# VAT baker and player

Standalone runtime/Editor package. Tools > UnityTools > VAT > Baker takes an animation root, one descendant SkinnedMeshRenderer, one AnimationClip and 1–120 FPS. It clones only Transform/bone hierarchy plus the selected renderer into a Preview Scene, samples animation/baked vertices, and saves a new VatClip asset with Mesh, linear point-filtered RGBAFloat position/normal textures and all-frame bounds. Original model/clip assets and scene transforms are not changed; prefab scripts, Animator and audio are not instantiated. Duplicate output assets are rejected. Dimensions respect maxTextureSize and total pixels are limited to 4,194,304. Failed newly-created output is cleaned up; existing assets are never deleted.

Create a MeshFilter + MeshRenderer + VatPlayer object. Explicitly assign MeshFilter, MeshRenderer and VatClip; assign a material using `UnityTools/VAT/Unlit`. The UI owner calls Init, TryPlay/TrySeek/Pause and Release. Player uses MaterialPropertyBlock, keeps shared Material unchanged, supports scaled/unscaled time and loop/one-shot. Shader interpolates adjacent baked frames by SV_VertexID; use supported desktop/mobile graphics APIs with shader model 3.5. This unlit shader has no package-specific URP include; actual pipeline/device rendering must be validated before shipping.

One asset represents one renderer/clip. Bake positions are renderer-local; generated object's transform should match the source renderer's placement. Root motion/animated renderer transform movement must be supplied separately by gameplay. Cross-fades, multi-renderer mesh combining, virtual bone tracks, animation events, lighting/shadows and custom shaders are not included. Normal texture is retained for a custom lit shader; bundled shader is unlit. Existing Module VAT assets use different serialization/property names and are not automatically migrated.
